# Chirichiro D.E.B Comprehensive School Website

Purple-and-gold Next.js website prepared for Vercel.

## Updates in this package

- Replaced the temporary generated crest with the actual Chirichiro D.E.B Comprehensive School logo extracted from the supplied school card.
- Added the real logo to both the navigation and footer.
- Added a floating WhatsApp contact button linked to `0704 622 570` (`+254704622570`).
- Kept the original purple school design and supplied campus/student photography.
- Updated Next.js/React package versions from the older vulnerable build used in the first draft.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production test

```bash
npm run build
```

## Deploy to Vercel

Push the project contents to the root of your GitHub repository, then import the repository into Vercel. The repository root should directly contain `app`, `public`, and `package.json`.
